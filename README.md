# Telegram Appointment Booking Bot

An asynchronous Telegram bot for booking service appointments. It is designed for appointment-based businesses such as barbershops, beauty services, tutors, and other providers who want clients to book a time slot directly in Telegram.

## Tech stack

- Python 3.12+
- aiogram 3
- python-dotenv

## Status

This project is under active development. The booking flow covers service, date and time selection with a confirmation step. Bookings are not saved yet and are lost on restart; persistence and the remaining features are being added step by step.
